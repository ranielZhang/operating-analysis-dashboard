## 3. 数据引擎 API（唯一取数入口）

```ts
import { store } from '@/domain/store';
import type { AnalysisFilter, Metrics, MetricRow, MonthlyPoint, ForecastPoint, CohortPoint, AlertItem } from '@/domain/types';
```

### 3.1 全局筛选条件

```ts
import { useAnalysisFilter } from '@/composables/useAnalysisFilter';
const { filter } = useAnalysisFilter();   // reactive，随筛选栏实时变化
```

`filter` 结构（`AnalysisFilter`）：

| 字段 | 类型 | 含义 |
|---|---|---|
| `startMonth` / `endMonth` | `'YYYY-MM'` | 期间（含端点） |
| `granularity` | `'year' \| 'quarter' \| 'month'` | 时间粒度 |
| `basis` | `'book' \| 'operating'` | **利润口径**：账面 / 经营 |
| `roiWindow` | `90 \| 180 \| 360` | 预估回收曲线窗口（天） |
| `centerIds` / `departmentIds` / `groupIds` / `pitcherIds` | `string[]` | 组织范围过滤 |
| `platformIds` / `projectIds` / `gameIds` | `string[]` | 业务范围过滤 |

> 组件必须写成 `computed(() => store.xxx(filter, ...))`，这样筛选条件一变自动重算。

### 3.2 查询方法

```ts
// 维度行（表格 / 柱图用）
store.queryRows(filter, groupBy, parentId?) : MetricRow[]
//   groupBy: 'company' | 'center' | 'department' | 'group' | 'pitcher'
//          | 'platform' | 'project' | 'game' | 'month'
//   parentId：下钻时传父节点 id（如 groupBy='game' + parentId='pj2' 取该项目下的游戏）
//   注意：不传 parentId 时，组织维度返回该层级全部节点；业务维度返回全部节点

// 单节点指标
store.metricsOf(filter, groupBy, key) : Metrics | null

// 时间序列（按 filter.granularity 自动分桶：年/季/月）
store.querySeries(filter) : MonthlyPoint[]        // { month, label, metrics }
// 强制按月
store.queryMonthSeries(filter) : MonthlyPoint[]

// 预警
store.alerts(filter) : AlertItem[]

// 月度滚动预估（实际 + 当月实时 + 未来 N 月）
store.forecast(filter, horizon = 6) : ForecastPoint[]

// Cohort 回收曲线（近 N 期投放，每 30 天一个点）
store.cohorts(filter, count = 8) : CohortPoint[]

// 常量
store.months           // string[]  全部月份 YYYY-MM
store.currentMonth     // '2026-06'
store.currentMonthIdx  // 相对 store.months 的下标
store.daysElapsed      // 当月已过天数 = 18
store.daysInMonth      // 当月天数 = 30
store.defaultFilter()  // 默认筛选条件
```

### 3.3 `Metrics` 字段全表（**页面只允许用这些字段**）

| 字段 | 含义 | 备注 |
|---|---|---|
| `revenue` | **当前口径**收入 | `basis='operating'` → 应计确认收入；`'book'` → 已到账收入 |
| `accrualRevenue` | 应计确认收入 | 经营口径收入（恒为应计，不随 basis 变） |
| `cashRevenue` | 已到账收入 | 账面口径收入 |
| `revenueByType` | `{ liuliangzhu, adGold, iapShare }` | 流量主收入 / 广告金 / 分成收入 |
| `businessCost` | **当前口径**业务成本 | `operating` → 投放消耗；`book` → 充值支出 |
| `laborCost` | 人工成本 | 工资+医社保+个税+项目奖金 |
| `adminCost` | 管理费用 | 福利费+办公费 |
| `totalCost` | 当前口径总成本 | businessCost + laborCost + adminCost |
| `costByType` | 见下方 `CostBreakdown` | 成本分项明细 |
| `profit` | **当前口径**利润 | 就是 `basis` 对应的那个利润 |
| `margin` | 当前口径利润率 | 小数（0.096 = 9.6%） |
| `bookProfit` / `operatingProfit` | 两种口径利润（恒定都算） | 用于双口径对比 |
| `profitGap` | `operatingProfit − bookProfit` | **口径差额**，核心信号 |
| `bookMargin` / `operatingMargin` | 两种口径利润率 | 小数 |
| `spend` | 投放消耗（本期） | |
| `prepay` | 充值额（本期） | 账面现金流出 |
| `prepayBalance` | 预付余额（时点） | 累计充值 − 累计消耗 |
| `receivable` | 应收未收（时点） | 存量用户未来价值 = 预估总回收 − 累计已回收 |
| `cashGap` | 现金缺口（时点） | `prepayBalance + receivable` |
| `forecastRoi` | 预估 ROI（**累计口径**） | 倍数，1.0 = 回本；= 累计预估总回收 / 累计消耗 |
| `actualRoi` | 实际 ROI（**累计口径**） | 倍数 |
| `recoveryRate` | 回收完成度（**累计口径**） | 小数 |
| `efficiencyRatio` | 人效比 | 经营利润 / 人工成本 |
| `headcount` | 人数（时点） | |
| `perCapitaProfit` | 人均经营利润 | |

> ⚠️ `forecastRoi` / `actualRoi` / `recoveryRate` **是自数据起点累计口径**（对齐现有系统「累计ROI」），不是本期口径。文案里要写「累计」二字避免误解。

`CostBreakdown` 字段：
`adSpend`(投放成本) / `prepay`(预付成本) / `salary`(工资) / `socialInsurance`(医社保) / `individualTax`(个税) / `projectBonus`(项目奖金) / `welfare`(福利费) / `office`(办公费)

`MetricRow` = `Metrics` + `{ key, name, parentId, depth, hasChildren, mom, yoy }`
`mom` / `yoy` 是**利润**的环比/同比（小数，可能为 `null`）。
`month` 维度的 `key` 是 `'YYYY-MM'`，`name` 是 `'6月'` 这类短标签。

import type { EChartsOption } from 'echarts';

const option = computed<EChartsOption>(() => ({
  grid: { left: 56, right: 24, top: 36, bottom: 28 },
  tooltip: {
    trigger: 'axis',
    axisPointer: { type: 'shadow' },

  legend: { top: 0, itemWidth: 10, itemHeight: 10, textStyle: { color: '#64748b', fontSize: 11 } },
  xAxis: {
    type: 'category',
    data: labels,
    axisLine: { lineStyle: { color: '#e2e8f0' } },

    axisTick: { show: false },
  },
  yAxis: {
    type: 'value',
    splitNumber: 5,
    axisLabel: { color: '#94a3b8', fontSize: 11, formatter: (v: number) => `${(v / 1e4).toFixed(0)}万` },
    splitLine: { lineStyle: { color: '#f1f5f9' } },

约定：
- 金额轴一律用「万」为单位（`toWan()` 或 `/1e4`），`tooltip.valueFormatter` 用 `money()`
- 折线 `smooth: false, symbolSize: 5, lineStyle: { width: 2 }`
- 双口径对比一律：账面 = `#4d94fa`、经营 = `#12b566`、差额 = `#ff9140`
- 有正负混合时加零线 `markLine`
- 容器必须有明确高度（`style="height: 300px"`）

## 9. 质检代理（A20）说明

1. `npx vue-tsc --noEmit`，修掉所有类型错误（不许用 `any` 大范围糊弄，不许 `@ts-ignore` 除非有充分理由并写注释）

3. 统一视觉：色值、圆角、字号、间距、图表 grid、表格密度
